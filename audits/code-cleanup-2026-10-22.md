## 1. Как сейчас устроен рабочий путь

Три посетительские страницы:

- `index.html`: экран запуска, видеосфера, глитч, копирование адреса, CTA, окно подписки.
- `about.html`: временный экран «Тут будет лендинг», ссылка на статью и городское видео справа.
- `article.html`: одна статья madk1d, её справки, изображения, песенные сцены, шапка, поиск и мобильная оболочка.

Дополнительные опубликованные страницы:

- `components.html`: рабочий каталог из 17 семейств и 53 вариантов, семь задач на дизайн.
- `component-preview.html`: отдельный исполняемый стенд для вариантов каталога.
- `glitch-test.html`: тест анимации заголовка.

Основные цепочки:

```text
index.html
  intro.js → video-sphere.js → drag-hint.js
           → headline-glitch.js
  subscribe-modal.js → components/action-button.js
  site-cursor.js
  dev-tools.js → [по условию] dev-panel.js → story-club-editor.js

about.html / article.html
  media-demo.js → media-views.js → article-view.js
                                → article-copy.js
                                → article-context-data.js
                                → article-context-view.js
                                → components/editorial-data.js
                                → components/editorial-typography.js
               → article.js → контроллеры статьи и мобильной оболочки
               → scene-rail.js → context-pager.js / components/context-title.js
               → editorial-video.js [сейчас нет подходящих узлов]
```

Сборка не собирает бандл и не удаляет неиспользуемые экспорты. Она генерирует статический HTML и копирует файлы. Это нормально для небольшого статического проекта, но требует явного списка того, что публикуется. Наличие файла в `dist` не означает его загрузку каждым посетителем: например, редактор DEV подключается динамически только по условию.
